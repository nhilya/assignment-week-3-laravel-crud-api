## 💭 Key Learnings

1.  **The Service Pattern**:
    -   I learned to move external API logic into a dedicated class (`App\Services\NoService`) instead of cluttering the Controller. This is a good practice for Separation of Concerns.
2.  **Dependency Injection**:
    -   I injected the service directly into the `destroy` method (`public function destroy(int $id, NoService $noService)`). I learned that Laravel's Service Container handles the instantiation automatically.
3.  **Resilience / Graceful Degradation**:
    -   I implemented a `try/catch` block and a fallback return value (`"Default message: Computer says no."`). If the external API fails (like the first URL did!), the app doesn't crash but degrades gracefully.
4.  **Laravel HTTP Client**:
    -   I used `Illuminate\Support\Facades\Http` (which wraps Guzzle) to make the GET request. It provides a fluent and easy-to-use interface for checking `successful()` responses.
